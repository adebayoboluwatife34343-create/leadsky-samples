Frequently asked questions.

Is this the official Coby Philips portal?

No. This is an independent digital design concept created by LeadSky for evaluation purposes. Coby Philips has not endorsed or launched this private concept.

How does skill matching calculation work?

In this prototype, candidate skill overlap is calculated by comparing user-entered or selected skills against fixed role requirement vectors. It is a keyword matching preview, not an automated hiring decision tool.

What components are required for a live platform?

A full production deployment requires authentication, encrypted data storage, GDPR compliance controls, database integration, live calendar booking APIs, and legal approval of contract templates.

Is my data saved or transmitted?

No. All candidate additions, search queries, and scheduling tests remain stored temporarily in browser memory and reset automatically upon page refresh.
